El curso, explicado paso a paso

Análisis Avanzado de Datos con Python · Subsecretaría de Energía · una página por laboratorio, con los datos del curso

Cómo se usan. Cada página cuenta un laboratorio de principio a fin, con las mismas tablas y cifras del cuaderno. Se avanza con los botones o con las flechas del teclado. Una barra arriba del escenario dice si hay que mirar o hacer algo. Abajo de cada paso hay botones para saber más. Se puede abrir antes de la clase, durante, o después para repasar, y no hace falta tener el cuaderno abierto.
